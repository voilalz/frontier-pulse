# 每日深读审查修订

依据《深读审查.pdf》，以 main 19ca563 为基线；用户已授权独立分支实施，不合并、不部署。

## 目标与边界

保留每日 08:00 的现有更新安排。新内容修订号 13，沿用 schemaVersion 2；每天 1–3 个主题，一个 800–1500 字主篇，最多两个 300–500 字短篇，目标正文 1500–3000 汉字。材料不足时明确标为简版，不用重复事实凑篇幅。合格主题至少 300 汉字、两条事实和一段分析；一篇合格主题即可独立发表，其他失败主题只留有绑定中文译名的标题和原文链接。

## 内容与校验

事实段按句绑定 1–3 个 evidenceId；数字、否定、限定词和说法归属规则先检查，再进行独立校对调用，只有 supported 才可公开。部分支持和不支持给具体句号、规则与重写反馈。分析、背景比较和后续问题与事实分开，显示编辑分析；禁止增加无依据的数字、引语和因果断言。标题、导语、主题问题以编辑层校验，不做英文子串匹配。校对结果绑定文本和证据摘要，改正文或引用必须重新校对。

## 选题与历史

保留原有新闻栏目；深读先去除评论、活动、纪念、招生、奖学金、犯罪和政治政策内容。对不同 eventId 的同一主体、同一行动、相近标题或相同金额报道聚类，合并真实来源与证据，不能因属于同一机构就误合并。选题不按正文长度排名，一手来源只作同等重要度的次序依据；有材料时包含 AI 或前沿技术。主题数为 1–3 时无法严格做到每类不超过 40%，按至多一篇同类主题、3 篇时最高 1/3 执行，稀疏期记录例外。

跨日按项目/型号精确键关联已捕获的旧证据，区分同事件与同项目。没有已捕获的历史证据就不生成历史事实。正文输入恢复 previousSameEvent，并传入此前项目背景及观察问题；新观察保存在日期稿，后续同项目输入核对，不把历史安排冒充当前成果。

## 发布、恢复和呈现

逐章生成、校对、最多一次定向修复；服务不可用、规则失败、语义不支持分别记入公开诊断，禁止输出 provider 异常正文。恢复保留已合格主题，只重写失败主题；不重新选择日报。新增上午恢复时点，10:00 后也仅修复缺章，不替换已合格正文。沿用完整旧稿最多一天，标题区固定显示当天未更新和内容日期；更早旧稿不得沿用，展示当天有证据的简讯。历史稿按旧契约显示旧版格式，证据绑定损坏仍不得冒充有效内容。

引用使用句末脚注和章末统一原文目录；一张主图，其余缩略图。日期选择保留当前发布日期；历史标题不冒充今日更新。部署与数据发布工作流仅 main 可写生产。

## 必要验证

用 10/8 真实冻结材料核对选题覆盖、重复与历史输入；用离线边界样本验证一章失败不拖掉合格章、独立语义拒绝增译、校对异常、一天沿用边界、缩写断句、归属和限定词。验证发布契约和桌面/手机渲染。离线模拟校对只证明程序控制流，不替代真实模型质量或 7 天线上稳定性验收。
