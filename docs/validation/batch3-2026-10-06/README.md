## 关键文件

- `research/classic-title-translations.json`：人工编写的显示译名；不属于冻结书目数据。
- `scripts/sync_classic_titles.py`：生成 / 检查前端译名表。
- `public/assets/classic-titles.js`：由接受目录英文原题与译名生成的显示映射。
- `public/assets/classic-context.js`：具体方法、来源绑定、主体及双向链接规则。
- `public/assets/classic-client.js`：中文检索，保持原快照哈希校验及引用行为。
- `public/assets/classic-papers.js`：中文标题、初次新闻上下文、卡片和反向入口。
- `public/assets/app.js`：保留来源证据及版本，新闻论文入口与中文说明。
- `public/index.html`、`public/assets/styles.css`、`public/sw.js`：入口、加载顺序、布局与缓存。
- `tests/test_classic_context.mjs`、`tests/test_classic_entry.mjs`：必要回归。

修改译名后运行生成命令即可；发布前用 `--check` 确认生成资源一致。不能直接修改
research/classics 或 public/classics 的历史数据来补中文标题。
